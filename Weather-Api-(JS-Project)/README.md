# 🌤️ Weather API

A simple JavaScript-based Weather App that lets you search for **any city** and instantly see its current weather. It comes with a fun twist — an **anime-themed background** on the page to make checking the weather a little more fun!

---

## 📖 About the Project

This project fetches real-time weather data for any city using a Weather API and displays it in a clean, simple interface. Along with the weather details, the page features an anime-related background design in the body to give it a unique look.

---

## ✨ Features

- 🔍 Search weather for any city in the world
- 🌡️ Displays current temperature, weather condition, and other details
- 🎨 Anime-themed background for a stylish UI
- ⚡ Built with simple, beginner-friendly JavaScript
- 📱 Responsive design (works on desktop & mobile)

## 🚀 Getting Started

Follow these steps to run the project on your local machine.

### 1. Clone the repository

```bash
git clone https://github.com/mrbantyxai-tech/Weather-Api--JS-Project-
```

### 2. Navigate to the project folder

```bash
cd weather-api
```

### 3. Add your API Key

```javascript
const APIKEY = "3d3a48958433692073a506ba2dbeb24a";
```

> 🔑 You can get a free API key from [OpenWeatherMap](https://openweathermap.org/api) or the weather API provider of your choice.

### 4. Open the project

Simply open `index.html` in your browser — no extra setup or server required!

---

## 📋 How to Use

1. Open the app in your browser.
2. Type the name of any city in the search bar.
3. Press **Enter** or click the **Search** button.
4. Instantly see that city's current weather details!
